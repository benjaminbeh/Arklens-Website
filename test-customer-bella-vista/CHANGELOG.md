## Template for Updates

```markdown
## [Date] - YYYY-MM-DD

### Added
- New features or content added

### Changed
- Changes to existing content or functionality

### Fixed
- Bug fixes or corrections

### Removed
- Content or features removed

### Customer Request
- Original request from customer (reference email/ticket)
```

```markdown

- Updated business hours for winter schedule
```
