## Prochaines Étapes

Une fois que vous avez complété ce formulaire :

1. **Enregistrez ce fichier** avec le nom de votre entreprise
2. **Rassemblez toutes les images** mentionnées ci-dessus
3. **Envoyez tout par e-mail à :** onboarding@arklens.ch
4. **Objet :** "Contenu du site web - [Nom de votre entreprise]"

Nous examinerons votre soumission et vous contacterons dans les 2 jours ouvrables pour :
- Confirmer que nous avons tout
- Répondre à toutes vos questions
- Planifier le lancement de votre site web
